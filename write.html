在浏览器里写，点「发布」直接提交到 GitHub 仓库，Pages 会自动重新部署。没有 Token 的人只能看，发不出去。

Token 只存在你浏览器的 localStorage，不进仓库、不上传到别处；发布 = 用它调用 GitHub API 往 assets/js/data.js 里插一篇。在 GitHub → Settings → Developer settings → Fine-grained tokens 生成，Repository access 只选这个仓库，Permissions 只给 Contents 的 Read and write。
