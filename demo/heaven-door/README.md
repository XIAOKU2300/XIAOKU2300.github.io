# Heaven's Door (天堂之门)
### 实时体积雾与神圣丁达尔光线追踪模拟 (Real-Time Volumetric Scattering & Vortex Simulation)

## 🌟 项目简介

本项目是一个基于 **Three.js** 与 **原生 GLSL 自定义着色器** 构建的纯前端 3D 艺术演示。通过**双通道深度感知光线步进管线 (Depth-Aware Raymarching Pipeline)**，模拟了一个充满神圣仪式感与超现实光影张力的“天堂之门”场景。

### 视觉与流体特性
1. **崇高极简主义构图 (Sacred Minimalist Architecture)**：
   - 包含 38 级微晶石质长阶，沿特定倾斜角度延伸至天门圣坛；
   - 阶梯顶端矗立着纪念碑式的极简巨石门框与纯白发光传送门核心；
   - 冷灰、低饱和的素描调性，主方向光斜向投下分明而立体的阶梯明暗交界线。
2. **乳白色体积雾与漩涡力场 (Vortex Volumetric Cascades)**：
   - 雾气从门框深处喷涌而出，受重力牵引沿阶梯向下蔓延翻滚（类似干冰瀑布效果）；
   - 在门框出口处受到由柯西-高斯角速度场驱动的**孔口主旋转涡 (Core Vortex Eye)**；
   - 沿阶梯下落时形成**双向开尔文-亥姆霍兹卷云剪切涡 (Bilateral KH Swirls)**；
   - 纯手写 3D Simplex 噪声配合 **定义域扭曲 (Domain Warping)**，表现真实流体的丝绢与卷须动感。
3. **动态神圣丁达尔光 (God Rays / Volumetric Light)**：
   - 圣光源穿射门洞，通过解析级孔径投影算法形成分明的四棱锥圣光柱；
   - 采用 **Henyey-Greenstein (HG) 各向异性相函数** 模拟强烈的前向散射（Forward Scattering）；
   - 光束与雾气深度耦合，随浓雾涡流滚入产生耀眼的动态光斑与 Beer-Lambert 消光自遮挡。
4. **神圣光尘粒子系统 (Holy Embers & Dust)**：
   - 1800 颗微粒在 GPU 顶点着色器中受漩涡流线牵引盘旋；
   - 在穿入丁达尔光束时由于高光散射而迸发出金白微光，离开光束后隐为幽静冷灰。

## 🎮 操作与交互

- **鼠标左键拖拽**：360° 环绕旋转视点
- **鼠标右键拖拽**：平移视角空间中心
- **滚轮滚动**：镜头焦距推拉缩放
- **按键 [F]**：一键切换全屏沉浸模式
- **右侧控制抽屉**：
  - `体积雾浓度 (Fog Density)`：无级微调雾气整体光学厚度
  - `漩涡演化流速 (Vortex Speed)`：调节流体气流翻滚与旋转速度
  - `丁达尔光束强度 (God Rays)`：调节穿透门洞的神圣强光辐射度
  - `前向散射因子 (Phase G)`：调节 Henyey-Greenstein 各向异性因子
  - `神圣星尘流速 (Holy Embers)`：控制悬浮光尘运动活跃度
  - `电影机位预设 (Camera Presets)`：
    - **仰望神迹**：位于长阶底端仰角，丁达尔光束正对镜头，HG 相函数爆发
    - **圣门俯瞰**：置于门框上方，纵览雾气如瀑布般顺级跌落展开
    - **侧翼卷流**：侧面观察气流漩涡在两翼的立体旋转与明暗交错
    - **门心凝眸**：近距离感受天门光涡与神圣星尘的交织
  - `启动电影漫游巡航`：自动开启平缓的环视慢镜头呼吸运镜

## 🛠️ 技术实现与架构细节

- **渲染管线**：
  - Pass 1: 渲染实体建筑与粒子至 `THREE.WebGLRenderTarget`，同步提取 16-bit 硬件深度缓冲 `depthTexture`。
  - Pass 2: 全屏正交 Quad 运行自定义光线步进片段着色器，利用世界空间反投影计算视线与几何体精确碰撞深度。
- **性能优化**：
  - **Slab AABB 包围盒求交裁剪**：射线只在阶梯与天门包围盒内步进，旷野天空零开销；
  - **Jorge Jimenez Interleaved Gradient Noise (IGN) 抖动**：消除固定步长的规则切片条纹；
  - **Beer-Lambert 提前退出**：当累积透射率低于 1.5% 时跳出循环；
  - **自适应 DPR 限制**：上限 1.5，保障高分屏与移动设备稳定 60 FPS；
  - **ACES Filmic 色调映射**：原生 GLSL 实现电影级高动态对比与纯白神圣滚降。
