# A Thousand Winds · 莫立于我墓前涕泣
### 沉浸式文学艺术与哲学体验空间 (Immersive Literary & Philosophical Sanctuary)

> *“Do not stand at my grave and weep,*  
> *I am not there. I do not sleep.*  
> *I am a thousand winds that blow...”*  
> —— Mary Elizabeth Frye (1932)

---

## ✦ 项目概述
本项目是基于美国诗人玛丽·伊丽莎白·弗莱（Mary Elizabeth Frye）于 1932 年创作的经典哲思悼亡诗《Do Not Stand at My Grave and Weep》打造的定制化网页艺术体验。作品突破千篇一律的组件库模板思维，以**泛神论存在、生命循环与宇宙全息重逢**为精神内核，融合典雅的书卷版式排版、视网膜级粒子物理动力学以及基于纯 Web Audio API 的算法生成式自然天籁。

---

## ✦ 文件结构
- `index.html`: 语义化文学主结构、双语诗篇、哲思边注、共生呼吸引导浮层与“寄意长风”互动祈念空间。
- `style.css`: 典雅纸本排版系统、晨暮/夜空模式切换、流体间距与动态光影质感样式。
- `script.js`:
  - 多态物理流场 Canvas 引擎（向量场千风、雪野碎钻、麦穗摇曳、秋雨涟漪、Boids鸟群协同、引力夜星与尾声曼陀罗）。
  - 纯 Web Audio API 算法生成式环境音景（粉红噪声滤波风息、开放和弦垫音、随机高阶微晶风铃）。
  - 普拉纳共生呼吸冥想控制器（4s吸气 / 4s持气 / 6s呼气 / 2s静止）。
  - “寄意长风”文字粒子化解构升腾交互与匿名记忆回响星座。
- `README.md`: 项目架构与艺术理念说明文档。

---

## ✦ 使用方式
1. 双击或使用任意现代浏览器（Chrome、Edge、Safari、Firefox）直接打开 `index.html` 即可完整体验。
2. **纯自包含与零依赖**：音频合成由浏览器原生 Web Audio API 实时运算生成，无需联网加载本地音频文件；字体若在离线环境下亦具备完善的宋体与衬线字体优雅降级方案。
